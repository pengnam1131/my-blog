## 글자 꾸미기

**굵게**, *기울임*, ~~취소선~~, `짧은 코드`, 그리고 <mark>형광펜</mark>을 쓸 수 있습니다. [링크](https://vercel.com)도 이렇게 겁니다.

> 인용문은 줄 앞에 `>` 를 붙입니다.

  - 이렇게요

## 이미지

이미지 파일은 `public/images` 폴더에 넣고 아래처럼 씁니다. 따옴표 안의 글은 사진 설명으로 표시됩니다.

```markdown
![사진 설명](/images/파일이름.jpg "사진 아래 캡션")
```

## 코드

````markdown
```js
const greet = (name) => `안녕하세요, ${name}님`;
```
````

위처럼 쓰면 아래처럼 보입니다.

```js
// 언어 이름을 적으면 색이 입혀집니다
const greet = (name) => `안녕하세요, ${name}님`;
console.log(greet("방문자"));
```

## 임시 저장

아직 공개하고 싶지 않은 글은 맨 위 정보에 `draft: true` 를 넣으면 사이트에 나오지 않습니다.
